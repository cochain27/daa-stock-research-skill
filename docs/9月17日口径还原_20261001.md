## 一、先纠正一个错误前提

**「9/17 标准蓄势唯一通过票是江淮」这句话不成立。**

`data/watch_history_backup/watch_history_2026-09-17.csv` 当日新增 3 行，看起来「只入池 3 只」，但**这是当天候选池经过下游过滤后的落盘子集**，不是当天候选池本身：

| 300750 | 宁德时代 | 近期超卖 | ✅ |

而**同日（9/17 11:43）晨报推送里的低位候选池是 19~21 只，全部是「📉超卖」路径**（见 `05_每日推送/推送_2026-09-17.md` 第三段）：

**江淮既不在晨报候选池里，也不在复盘候选表里**（复盘候选表只有东财/宁德/兆易 3 只，同样全超卖）。grep 两个文件，`江淮` 命中 **0 次**。

**所以：「江淮是当天标准蓄势唯一通过票」是误读。真相是：9/17 当天标准蓄势路径几乎没出票，江淮是极少数（甚至可能是唯一）通过标准蓄势的票，但它并没有被"当天唯一"这件事特别选中——它是被下游过滤链筛剩下来的。**

## 二、为什么晨报候选 19 只全超卖、江淮不在其中

### 关键：标准蓄势判据里有一条 `候选日涨幅 ≤ 5%`

1cc3e00（09-12）版 `_蓄势通过()` 的判据（八条）：

```
① pos60 < 0.55        （60日位置）
② dist60 ≤ -25%       （距60日高）
③ lb ≤ 1.30 且 lb5mean ≤ 1.20   （缩量）
④ 5日涨幅 ∈ [-10%, +5%]          （横盘）
④b 候选日本身涨幅 ≤ 5%           （防追已启动票）★
⑤ amp20 < 30%         （波动收敛）
⑥ 成交额 ∈ [2亿, 15亿]
```

### 晨报候选 19 只全部卡在 ④b 或 ⑥

- 东财 23.8 亿 / 宁德 105.0 亿 / 兆易 86.9 亿 / 中际旭创 204.2 亿 …… **全部 ≫ 15 亿上限** → 标准蓄势 ⑥ 直接排除。
- 它们能进池，是因为走了**「近期超卖」路径**——该路径**当年没有成交额上限**（`LOW_POS_ENTRY_RECENT_OVERSOLD_*` 只卡 pos60<0.65 与 dist60<-30%），且**绕过了 ④b 候选日涨幅检查**（09-12 版注释：「超卖路径绕过了候选日涨幅检查，已补上」——但补的是 `chg_today > MAX_CHG_TODAY` 这一条，仍在能进的范围内）。

**这就是 19 只 = 102 只大票 + 少数小票，全部挂着 📉超卖的全部原因**：那一天的**标准蓄势通过票本来就非常少**，因为当天市场处于震荡偏弱（温度 42/100），绝大多数活跃票的**位置都不够低**（pos60 高）或**成交额超 15 亿**。

### 江淮为什么能通过标准蓄势

- 成交额 13.22 亿 ✅（< 15 亿上限）
- pos60 = 0.071（7.1%）✅
- dist60 = -31.7%（按 19.39 计算）✅
- 缩量（量比 0.73）✅
- 5日涨幅 +2.4% ✅
- 候选日涨幅 +1.0% ✅（< 5%）
- amp20 ✅

**八条全过** → 江淮是当天**标准蓄势路径的极少数通过票**之一。

## 三、那「回放通过 132/180 只」是怎么回事

回放脚本（`audit_jh_0917.py`）本地跑：

| 口径 | 通过只数 | 江淮名次 |
|---|---|---|
| 9/12 口径（POS60<0.55 / 额 2-15 亿 / 无 MA20 / 无截断） | **180** | 64 |
| 09-23 收紧口径（POS60<0.40 / 额 ≤6 亿） | 78 | ❌ 不通过（额 13.22 亿 > 6 亿）|
| 当前口径（POS60<0.40 / 额 ≤15 亿 / MA20 软排序） | **132** | 36 |

**回放的 180/132 只 ≠ 当天实跑的标准蓄势通过票数。** 差异来自三处，全部是「票池」而非「判据」：

### 差异 1：回放用的是本地 K 线全 A 池，实跑用的是「成交额前 600 名」

```python
# pick_low_pos_entry 内部
snap = snap.sort_values("_amt", ascending=False).head(top)   # daily_report/close_review 传 top=600
```

9/17 前 600 名门槛 = **4.99 亿**，实际参与判据的只有这 600 只。

本地回放扫的是**全 A 场 ~5000 只**，通过数自然高出 3~5 倍。**这是数量级差异的主因。**

### 差异 2：回放的本地 K 线是"最新"数据，含 9/17 之后的行情

`_indicators()` 里 `pos60` / `dist60` / `amp20` / `lb5mean` 都是**滚动窗口**。本地 CSV 已经更新到 10/01，回放时如果直接取「9/17 那天的那一行」，用的是**当时的日期切片**（脚本里 `h = h[h["日期"] <= ts]`），这一块是对的；但**如果脚本忘了切**，指标就会被后续行情污染。需要确认。

### 差异 3：行业去重 MAX_SAME_INDUSTRY=1

9/12 版 `pick_low_pos_entry` 尾部有行业去重（`MAX_SAME_INDUSTRY=1`），能砍掉一部分同行业重复票。当前版本已移除该逻辑。**这一条能砍量，但砍不到 1 只。**

## 四、根因定论

| 说法 | 判定 |
|---|---|
| ❌「9/17 标准蓄势唯一通过票是江淮，截断/路径改动导致抓不到」 | **前提错误**。江淮不是"唯一通过票"；截断（topN=3）只在通过票 > 3 时起作用，9/17 标准蓄势通过票本来就少，**截断不构成变量**（用户判断正确）。 |
| ❌「删超卖路径后江淮更应被选出」 | **方向对，但现实里晨报的 19 只超卖票全部走的是超卖路径，删掉超卖路径后它们会全部消失——江淮确实会更"凸显"，但它是靠"别人消失"凸显，不是靠"自己变强"凸显。** |
| ✅ **真正的口径事实** | ①9/17 实跑**标准蓄势通过票极少**（因震荡偏弱+位置不够低+成交额超限三重叠加）；②江淮是其中一只，**入池属实**（watch_history 铁证）；③晨报候选池 19 只全超卖，说明**当天出票主力是超卖路径**，标准蓄势是长尾；④**回放 132/180 只 ≠ 实跑口径**，回放扫全 A，实跑只扫成交额前 600 名——**这是数量级差异的唯一真实原因**。 |

## 五、对「新口径能否抓到江淮」的影响

**不变。** 新口径抓不到江淮的卡点是 **MA20 软排序**（江淮启动前 MA20 全程下行，被无条件后置到 36/132），与「9/17 实跑为什么只落 3 只」是**两个独立问题**。

- 「9/17 落 3 只」= 票池 + 出票结构问题（已在本文件解释）。
- 「新口径抓不到江淮」= 排序键问题（`docs/江淮汽车_新策略口径回溯_20261001.md` 已定型）。

两者都成立，互不矛盾，也互不解释。
