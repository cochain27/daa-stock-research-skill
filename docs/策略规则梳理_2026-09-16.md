## 一、三大通道总览

系统有三条并行的选股通道，各自定位不同、互不替代，温度闸门是共同的最高优先级开关。

| 通道 | 定位 | 开仓温度闸门 | 持有周期 | 每日上限 |
|---|---|---|---|---|
| **低位启动（左侧埋伏）** | 蓄势→放量突破的左侧埋伏 | 触发日温度 ≥55 | T+3~T+5 | — |
| **右侧趋势（波段）** | 横盘后温和放量突破的右侧确认 | 温度 ≥55 | 2~4 周 | 2 只 |
| **短线激进（情绪博弈）** | 情绪驱动/首板接力 | 温度 ≥50 + 涨停≥50家 | 3 天 | 2 只 |

**当前市场温度 38（09-15），三通道温度闸门全部关闭 → 均休战，这是设计使然的空仓纪律，不是 bug。**

## 二、低位启动通道（最核心，双路径）

### 2.1 入池（候选）判据

候选池是「T-1 蓄势扫描」，分两条路径：

**路径A — 标准蓄势**（8 条全部满足才入池）：

| # | 条件 | 阈值 |
|---|---|---|
| ① | 60日位置 | < 55% |
| ② | 距60日高点 | ≤ -25% |
| ③ | 前1日量比 | ≤ 1.30 |
| ③b | 5日量比均值 | ≤ 1.20 |
| ④ | 5日涨幅 | -10% ~ +5% |
| ④b | 候选日本身涨幅 | ≤ 5%（防追已启动） |
| ⑤ | 20日振幅 | < 30% |
| ⑤ | 蓄势日成交额 | 2亿 ~ 15亿 |

**路径B — 近期超卖**（放宽，过去25个交易日出现过以下任一即算）：

| 条件 | 阈值 |
|---|---|
| 60日位置曾 | < 50% |
| 或 距60日高点曾 | < -30% |

> 超卖路径位置上限放宽到 65%（超卖修复后位置天然偏高）。

### 2.2 触发（升级为买入推荐）判据

候选 ≠ 推荐。候选票必须 T 日实时满足**同时 5 条**才升级：

| 条件 | 标准蓄势 | 近期超卖 |
|---|---|---|
| 量比 | ≥2.0 且 ≤7.0 | ≥2.0 且 ≤7.0 |
| 涨幅 | 10% ~ 15% | 9% ~ 15% |
| 成交额 | 4亿 ~ 16亿 | 4亿 ~ 16亿 |
| 破 MA20 | 是 | 是 |
| 大盘温度 | ≥55 | ≥55 |

### 2.3 风控（标准蓄势专属）

- 止损 -8%，止盈1 +5%、止盈2 +7%，持有 T+3
- 超卖路径：止损 -8%，持有 T+5

### 2.4 体检层（每日重检，2026-09-16 已修正）

候选池每日重检，剔除失效票。**仅保留两条判据**（2026-09-16 删除了「距高」「位置」两条，因与选股层反向矛盾）：

| 保留判据 | 阈值 |
|---|---|
| 近20日振幅 | < 15% |
| 近20日 std/均价 | < 4% |

> 已删除：`距高 > -22%`、`位置 ∈ [20%,40%)` 两条——它们用更严且反向的尺子复判选股层已放行的票，结构性误杀「深超跌+底部反转」。

## 三、右侧趋势通道（波段）

| 条件 | 阈值 |
|---|---|
| 流通市值 | ≥30亿 |
| 60日位置 | 30% ~ 70% |
| 近20日振幅 | < 25% |
| 近20日 std/均价 | < 5% |
| 放量突破 | 量 ≥ 20日均量 × 1.5 |
| 突破涨幅 | 3% ~ 7%（温和，拒绝涨停追高） |
| 成交额 | > 1.5亿 |
| 温度 | ≥55 |
| 持仓 | 2~4 周，展期硬上限 60 天 |
| 止损 | -6%（MA20 结构止损优先） |

> 关键：右侧趋势**刻意拒绝涨停板**（涨幅上限 7% + 近涨停剔除），要的是「横盘后温和放量突破」，与左侧埋伏「放量突破」、短线「追涨」是三种不同画像。

## 六、关键结论与待办

1. **三池空是正常休战**：温度 38 < 所有闸门（50/55），弱势市空仓是纪律。
2. **触发涨幅 9-15% 是否过高**：10% 下限有数据支撑（分水岭），15% 上限样本仅 3 只且收益反而最高，需扩样本再议。
3. **待办**：「15% 涨幅上限」建议放宽回测验证；`watch_history` 已改 append-only 增量写，数据不再丢失。
