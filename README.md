# daa-stock-research · 大A每日投研系统（WorkBuddy Skill 版）

> A股个人投资者每日投研自动化：晨报荐股 → 双策略跟踪池连续跟踪 → 止盈/止损/展期生命周期管理 + 虚拟盘净值复盘。
> 本项目为可复用的 Skill 打包版，原始数据源全部为免费公开接口（akshare + 腾讯行情）。

## 功能

- **双策略并行（2026-09 重构）**
  - 📈 **右侧趋势**：横盘放量突破启动，目标持仓 2-4 周（可展期至 60 天），右侧追趋势中继
  - ⚡ **短线激进**：情绪驱动（涨停梯队/炸板率），3 天持股（T日开盘买 → T+2日开盘卖），配套 3 日回测台账
  - 🧊 **冰点抄底**：市场温度 ≤35 时，允许选 0-2 只被错杀的强势票
- **盘前晨报**：市场温度(0-100) + 仓位建议 + 双通道候选股（六维评分 / 买点区间 / 止损 / 双档止盈）
- **选股引擎**：右侧追启动（放量突破20日新高）、涨停剔除、行业去重、代码白名单（无科创板权限）
- **推荐池跟踪**：推荐股写入台账，收盘自动更新状态机（持有中→止盈减半→清仓/止损/到期/技术离场）
- **展期机制**：趋势票 2-4 周后可展期（少数派，≤2只），展期后止盈切换 +10%/+15%
- **虚拟盘**：推荐即虚拟成交（实时价入账），双策略独立虚拟净值/胜率/累计统计
- **三类复盘 + 盘中监控**：午间复盘 / 收盘复盘 / 每15分钟盘中触发告警，微信推送

## 快速开始

```bash
pip install -r requirements.txt
python scripts/daily_report.py    # 生成日报 + 可选微信推送
```

配置与定时化建议详见 [SKILL.md](SKILL.md)。
