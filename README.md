# daa-stock-research · 大A每日投研系统（WorkBuddy Skill 版）

> A股个人投资者每日投研自动化：晨报荐股 → 多策略跟踪池连续跟踪 → 止盈/止损/技术离场生命周期管理 + 虚拟盘净值复盘。
> 本项目为可复用的 Skill 打包版，原始数据源全部为免费公开接口（akshare + 腾讯行情）。

## 功能

### 三正式策略 + 一观察池（2026-09 定版）

| 策略 | 定位 | 持股周期 | 出场规则 | 台账 |
|------|------|----------|----------|------|
| 📈 右侧趋势池 | 横盘放量突破，追趋势中继 | 2-4 周（可展期至 60 天） | -6% 硬止损 + 破 MA20 结构止损 + 破 MA10 移动止盈 | `推荐台账_右侧趋势.csv` |
| ⚡ 短线激进池 | 情绪驱动，快进快出 | 3 天（T日开盘买 → T+2日开盘卖） | -5.5% 止损 + +5% 减半移动止损 + 3天浮亏时间止损 | `推荐台账_短线激进.csv` + `短线回测台账.csv` |
| 🌊 温和放量初动池 | 低位蓄势初动（独立选股器） | T+5 | T+1 开盘介入 / -8% 硬止损 / T+2 收盘起破 MA5 次日离场 / 无固定止盈 / 最长 T+5 | `策略笔记本_温和放量初动池.md` |
| 👀 低位埋伏观察池 | 蓄势贴前高、尚未启动 | 仅观察，不给买入推荐 | 研究观察，非买入信号 | `策略笔记本_低位埋伏观察池.md` |

- **初动池**是独立选股器（自有参数），非低位池子集；同属「低位蓄势→启动」研究线。
- **低位池**只挂观察不荐股；入选口径：成交额≤6亿 + 60日位置≤0.40 + 距60日高≤-27% + MA20乖离≥-5% + MA20上行 + 振幅<25 + 量比≤2.0，展示端截断 top3。

### 核心能力

- **盘前晨报**：市场温度(0-100) + 仓位建议 + 多通道候选股（评分 / 买点区间 / 止损 / 硬止损）
- **选股引擎**：右侧追启动（放量突破）、涨停剔除、行业去重、代码白名单（无科创板权限）
- **推荐池跟踪**：推荐股写入台账，收盘自动更新状态机（持有中→止盈减半→清仓/止损/到期/技术离场）
- **展期机制**：趋势票 2-4 周后可展期（少数派，≤2只），展期后止盈切换 +10%/+15%
- **虚拟盘**：推荐即虚拟成交（实时价入账），各策略独立虚拟净值/胜率/累计统计
- **四类复盘 + 盘中监控**：午间复盘 / 收盘复盘 / 每15分钟盘中触发告警，微信推送
- **策略笔记本**：每策略一本，自动记录每日推荐流水 + 跟踪状态（`data/笔记本/`）

## 快速开始

```bash
pip install -r requirements.txt
cd scripts && .venv/bin/python _run_daily_wrapper.py    # 生产晨报（含推送）
```

> ⚠️ 生产环境必须走 `_run_daily_wrapper.py`，不要直跑 `daily_report.py`（akshare 快照接口无超时，链路抖动会永久挂起）。详见 [SKILL.md](SKILL.md)。

## 数据源

| 用途 | 来源 |
|------|------|
| 涨停池/跌停池/板块/资金流 | akshare（东方财富接口） |
| 个股K线/实时行情 | akshare + 腾讯行情（qt.gtimg.cn） |
| 盘口量比/五档 | 腾讯行情 |
| 估值(PE/PB历史分位) | akshare + 百度兜底 |
| 行业热度 | 同花顺二级行业板块 + 东财批量接口 |
