## 核心研究结论

- 样本：132 交易日 / 1188 只 / 16743 条低位信号。
- 基线转化率（低位池→趋势池真正启动）：**10.5%**。

## 行业热度归因

| 结论 | 数据 |
|---|---|
| 对转化率 | 几乎无增益（冷门10.0% vs 主线11.1%） |
| 对7日胜率 | 明显提升（46.2→48.0%） |
| 叠加前兆剔劣后7日胜率 | 45.5→53.3%，7日均收 -0.06→+0.49% |
| 窗口敏感性 | W5 显著、W10/W20 衰减（短期效应） |

## 落地结论

1. 剔劣三件套 → 硬过滤（转化率 10.5%→16.1%）。
2. 位置/成交额 → 硬过滤（2026-09-12 由排序加分升级）。
3. 行业热度 → 仅排序加分，不硬过滤（避免砍样本）。
4. 启动豁免 → 当日涨幅≥7% 跳过所有深跌/位置/成交额过滤。
