# 定期复盘 · 模板与节奏

> 目的：定期复盘三个池子的持仓与交易，沉淀"策略哪里赚、哪里亏、怎么改"，形成闭环。  
> 节奏：**每日（自动）→ 每周（人工）→ 每月（人工）**。数据源见各本子。

## 一、复盘节奏

| 频率 | 触发   | 动作                                   | 产物                |
| -- | ---- | ------------------------------------ | ----------------- |
| 每日 | 收盘自动 | `close_review.py` 体检三池持仓 + 净值 + 次日关注 | `04_每日复盘/复盘_*.md` |
| 每周 | 每周末  | 人工填「周复盘清单」                           | 追加到本本子「周复盘记录」     |
| 每月 | 每月末  | 人工填「月复盘清单」+ 回测复查                     | 追加到本本子「月复盘记录」     |

## 二、周复盘清单（每周末填一次）

### 1. 持仓体检

- [ ] 三池各剩哪些持仓？状态（持有/待止损/待止盈）？
- [ ] 本周新开仓几只？依据什么信号？
- [ ] 本周了结几只？方式（止损/止盈/时间/移动止损）？已实现盈亏？

### 2. 交易复盘（对每笔已了结交易）

| 字段        | 内容                  |
| --------- | ------------------- |
| 代码/名称     |                     |
| 建仓价 → 了结价 |                     |
| 了结方式      | 止损 / 止盈 / 时间 / 移动止损 |
| 盈亏        | ¥ + %               |
| 入场是否符合信号  | 是 / 否（偏差在哪）         |
| 出场是否守纪律   | 是 / 否（贪/慌/扛）        |
| 教训        | 一条                  |

### 3. 策略表现

- [ ] 本周三池胜率、平均收益、盈亏比 vs 回测基准？（偏差>20% 要查因）
- [ ] 哪个池子在亏？是策略失效还是执行问题？
- [ ] 温度档位与实际仓位是否一致？

### 4. 策略改进（本条闭环核心）

- [ ] 本周踩了哪些坑？→ 记入踩坑日记。
- [ ] 哪些过滤/阈值要改？→ 改 config.py 后必须跑回测验证，再把结论写回对应回测本。
- [ ] 哪些新观点要沉淀？→ 记入观点学习日记。

## 三、月复盘清单（每月末填一次）

- [ ] 本月累计收益率 vs 上证/沪深300 基准？（跑赢还是跑输）
- [ ] 最大回撤多少？发生在哪个池子、哪类行情？
- [ ] 本月三池各自净贡献（谁赚钱、谁拖后腿）？
- [ ] 回测基准是否过时？→ 若有新参数，重跑回测更新 3 本回测本。
- [ ] 下月策略方向：加仓/降仓/停用某池？温度闸门是否要调？

**4. 策略改进（闭环核心）**

- **【踩坑·最高优先】持有天数用"自然日"而非"交易日"**：`tracker_common.py:133`、`short_tracker.py:245` 用 `datetime.days` 自然日差算持有天数，`SHORT_TIME_STOP_DAYS=3` 被"周五建仓→周一"3自然日=1交易日提前触发。已记踩坑日记。修法：改用交易日历（上证000001 K线）算跨度。**改前须回测验证**（会改变历史结算口径）。
- **阈值**：本周暂不改（样本不足）。待验证项：① 短线时间止损是否应要求"≥N交易日"而非自然日；② 初动池在温度<50 时是否应降低同时开仓数/下调均值预期。
- **观点**：弱市趋势延展弱→初动池均值压缩、破MA5离场占比升高（已记观点学习日记）。

**5. 低位观察池本周命中率（`--since=2026-10-12`）**

- 本周入池 **12只**，有效样本 **9只**（10-15入池的粤电力A/海正药业/南华期货无T+1数据）。
- T+1 均值 **-0.96%** 胜率 **33%**（3/9）；T+3 均值 **-5.70%** 胜率 **0%**（仅3条有数据）；T+5 无数据（本地K线只到10-16）。
- 涨停率 **0%**；7日最大涨幅均值 +1.26%、≥5%概率 **0%**；破止损率 **44%**（4/9：中国卫星、横店东磁、海格通信、宁波韵升）。全部标准蓄势路径。
- 结论：弱势环境下"入池即破位"比例高（44% vs 全样本69% 略好但仍差），低位池本周期转化价值兑现差，无可操作标的。

**周度结论**

- 本周正式策略结算/信号合计 8 笔（短线结3 + 初动信号5）；正式结算 3 笔全负，且 2 笔系**持有天数口径误杀**；初动5信号均值+0.81% 显著低于基线 4.2%。
