# 定期复盘 · 模板与节奏

> 目的：定期复盘四个池子（短线/趋势/初动/低位触发）的持仓与交易，沉淀"策略哪里赚、哪里亏、怎么改"，形成闭环。  
> 节奏：**每日（自动）→ 每周（人工）→ 每月（人工）**。数据源见各本子。

## 一、复盘节奏

| 频率 | 触发   | 动作                                   | 产物                |
| -- | ---- | ------------------------------------ | ----------------- |
| 每日 | 收盘自动 | `close_review.py` 体检四池持仓 + 净值 + 次日关注 | `04_每日复盘/复盘_*.md` |
| 每周 | 每周末  | 人工填「周复盘清单」                           | 追加到本本子「周复盘记录」     |
| 每月 | 每月末  | 人工填「月复盘清单」+ 回测复查                     | 追加到本本子「月复盘记录」     |

## 二、周复盘清单（每周末填一次）

### 1. 持仓体检

- [ ] 四池各剩哪些持仓？状态（持有/待止损/待止盈）？
- [ ] 本周新开仓几只？依据什么信号？
- [ ] 本周了结几只？方式（止损/止盈/时间/移动止损）？已实现盈亏？

### 2. 交易复盘（对每笔已了结交易）

| 字段        | 内容                  |
| --------- | ------------------- |
| 代码/名称     |                     |
| 建仓价 → 了结价 |                     |
| 了结方式      | 止损 / 止盈 / 时间 / 移动止损 |
| 盈亏        | ¥ + %               |
| 入场是否符合信号  | 是 / 否（偏差在哪）         |
| 出场是否守纪律   | 是 / 否（贪/慌/扛）        |
| 教训        | 一条                  |

### 3. 策略表现

- [ ] 本周四池胜率、平均收益、盈亏比 vs 回测基准？（偏差>20% 要查因）
- [ ] 哪个池子在亏？是策略失效还是执行问题？
- [ ] 温度档位与实际仓位是否一致？

### 4. 策略改进（本条闭环核心）

- [ ] 本周踩了哪些坑？→ 记入踩坑日记。
- [ ] 哪些过滤/阈值要改？→ 改 config.py 后必须跑回测验证，再把结论写回对应回测本。
- [ ] 哪些新观点要沉淀？→ 记入观点学习日记。

## 三、月复盘清单（每月末填一次）

- [ ] 本月累计收益率 vs 上证/沪深300 基准？（跑赢还是跑输）
- [ ] 最大回撤多少？发生在哪个池子、哪类行情？
- [ ] 本月四池各自净贡献（谁赚钱、谁拖后腿）？
- [ ] 回测基准是否过时？→ 若有新参数，重跑回测更新 3 本回测本。
- [ ] 下月策略方向：加仓/降仓/停用某池？温度闸门是否要调？
