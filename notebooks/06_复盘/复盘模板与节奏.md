# 定期复盘 · 模板与节奏

> 目的：定期复盘三个池子的持仓与交易，沉淀"策略哪里赚、哪里亏、怎么改"，形成闭环。  
> 节奏：**每日（自动）→ 每周（人工）→ 每月（人工）**。数据源见各本子。

## 一、复盘节奏

| 频率 | 触发   | 动作                                   | 产物                |
| -- | ---- | ------------------------------------ | ----------------- |
| 每日 | 收盘自动 | `close_review.py` 体检三池持仓 + 净值 + 次日关注 | `04_每日复盘/复盘_*.md` |
| 每周 | 每周末  | 人工填「周复盘清单」                           | 追加到本本子「周复盘记录」     |
| 每月 | 每月末  | 人工填「月复盘清单」+ 回测复查                     | 追加到本本子「月复盘记录」     |

## 二、周复盘清单（每周末填一次）

### 1. 持仓体检

- [ ] 三池各剩哪些持仓？状态（持有/待止损/待止盈）？
- [ ] 本周新开仓几只？依据什么信号？
- [ ] 本周了结几只？方式（止损/止盈/时间/移动止损）？已实现盈亏？

### 2. 交易复盘（对每笔已了结交易）

| 字段        | 内容                  |
| --------- | ------------------- |
| 代码/名称     |                     |
| 建仓价 → 了结价 |                     |
| 了结方式      | 止损 / 止盈 / 时间 / 移动止损 |
| 盈亏        | ¥ + %               |
| 入场是否符合信号  | 是 / 否（偏差在哪）         |
| 出场是否守纪律   | 是 / 否（贪/慌/扛）        |
| 教训        | 一条                  |

### 3. 策略表现

- [ ] 本周三池胜率、平均收益、盈亏比 vs 回测基准？（偏差>20% 要查因）
- [ ] 哪个池子在亏？是策略失效还是执行问题？
- [ ] 温度档位与实际仓位是否一致？

### 4. 策略改进（本条闭环核心）

- [ ] 本周踩了哪些坑？→ 记入踩坑日记。
- [ ] 哪些过滤/阈值要改？→ 改 config.py 后必须跑回测验证，再把结论写回对应回测本。
- [ ] 哪些新观点要沉淀？→ 记入观点学习日记。

## 三、月复盘清单（每月末填一次）

- [ ] 本月累计收益率 vs 上证/沪深300 基准？（跑赢还是跑输）
- [ ] 最大回撤多少？发生在哪个池子、哪类行情？
- [ ] 本月三池各自净贡献（谁赚钱、谁拖后腿）？
- [ ] 回测基准是否过时？→ 若有新参数，重跑回测更新 3 本回测本。
- [ ] 下月策略方向：加仓/降仓/停用某池？温度闸门是否要调？

## 五、月复盘记录（按月份追加）

### 2026-09（首月复盘 · 样本极薄，结论仅定性参考）

> 统计窗口：虚拟盘 2026-09-01 ~ 09-24；上证指数基准数据截至 09-18（本地 K 线未补 09-21 后）。初动池 09-20 升级正式、右侧趋势 09-24 才修 bug，本月实盘样本极少。

**1. 累计收益率 vs 基准**
| 项 | 数值 |
|---|---|
| 上证指数（08-31→09-18 收盘） | -1.87% |
| 上证指数 9 月最大回撤 | -3.06%（3986→3864，09-15） |
| 短线激进（虚拟盘，09-07 起） | -0.04%（净值 99956） |
| 右侧趋势（虚拟盘） | +0.00%（空仓） |
| 温和放量初动 | 未接虚拟盘 |
| 两正式池合计 | 约 -0.02%（-44 元 / 20 万） |

结论：两正式池合计约 -0.02%，略跑赢上证 -1.87%，但仓位极轻、样本不足（短线仅 4 笔已了结、趋势 0 笔），跑赢无统计意义。沪深 300 本地无数据，下月补齐。

**2. 最大回撤及发生场景**
- 虚拟盘层面：净值回撤极浅（-0.04%），因仓位轻、样本少，非真实风险暴露。
- 单笔层面：短线最大单笔 -4.98%（新华百货，09-07 建仓→09-09 触发止损）。
- 初动信号当前最大浮亏 -5.8%（汉得信息，09-22 信号 T+3）。
- 场景：全月弱势震荡（收盘温度 37~42，多数 <50），情绪普跌、量能尚可但趋势不明，短线闸门多日休战。

**3. 三池各自净贡献**
| 池 | 净贡献 | 说明 |
|---|---|---|
| 短线激进 | -44 元（-0.04%） | 唯一有已实现盈亏的池；4 笔已了结，胜率 25%/均值 -0.11%，显著弱于基线 47.7%/+0.44%（样本过少） |
| 右侧趋势 | 0 | 结构性 bug 空转整月（AVG_VOL20 未生产→候选 100% 跳过），09-24 修复，尚未出首笔 |
| 温和放量初动 | 0 | 09-20 升级正式但未接虚拟盘；8 笔信号（09-21~24）当前全浮亏，待 T+5 走完判定 |
| 低位观察（非正式） | 不入账 | 江淮汽车 09-17 入池→09-23 触发 +20.9%，研究价值正面 |

→ 结论：台账 `docs/策略台账_2026-09-20.md` 已连续记录 09-20~09-24 全部参数变更，但 3 本回测本自 09-12/09-13 后未同步。重跑命令已固化于台账，需人工执行：`backtest_engine.py --cache` 长窗口（策略1/2）、low_pos 系列（观察池）、`warm_start_backtest.py`（初动）。本次未自动重跑（耗时长 + 幸存者偏差/不复权局限，属人工研究动作）。

**5. 下月方向**
- 仓位：维持防守（10-30%）。全月温度 <50、短线/趋势闸门多日休战；等温度≥50 且涨停家数回升再抬仓。
- 温度闸门：暂不调。S5/T9 温度门控已证伪（无增益），维持 SHORTLINE_TEMP_MIN=50 / 趋势温度≥55。
- 趋势池：09-24 刚修 bug，10 月重点验证能否正常出票、突破票质量。
- 初动池：优先补台账待办 #6——接入虚拟盘跟踪（登记→MA5/硬止损→T+5 到期全链路），否则净贡献永远无法量化。
- 低位池：09-24 A+B+距高-27 刚落地，10 月实盘验证转化率是否兑现 15.54%、空窗天是否可接受（-27 有 25.8% 空窗）。
