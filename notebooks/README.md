# 交易策略本子库（notebooks）

> 这是 A 股每日投研系统的**策略笔记库**，与 `SKILL.md`（说明文档）、`scripts/config.py`（参数权威值）配套。
> 分工：**本子库记「为什么这么做 + 历史演变」，config.py 记「当前生效的数值」**。改策略时两边同步改。

## 三个池子口径

| 池子 | 定位 | 温度闸门 | 目标持仓 | 源码 |
|---|---|---|---|---|
| 右侧趋势池 | 波段右侧追启动，横盘突破 | ≥55 | 14-28 天（展期≤60天） | stock_screener 趋势通道 |
| 短线激进池 | 情绪驱动，涨停梯队/接力 | ≥50 | 3-5 天 | stock_screener 短线通道 |
| 低位启动观察池 | 蓄势贴前高，埋伏启动 | 无（观察池，非买入） | 观察→转化趋势池 | low_pos_watch |

## 数据源（台账落盘位置）

- 右侧趋势台账：`data/推荐台账_右侧趋势.csv`
- 短线激进台账：`data/推荐台账_短线激进.csv`
- 虚拟交易流水：`data/虚拟交易.csv`
- 低位观察历史：`data/watch_history.csv`
- 回测汇总：`data/回测_策略汇总.csv`、`data/回测_胜率优化对比.csv`

## 维护约定

1. 每本持仓记录：每日复盘后追加当日变动（来源 `04_每日复盘/复盘_*.md`）。
2. 每本回测：改了规则/参数跑完回测后，在对应回测本追加一条结论 + 数据来源 CSV。
3. 踩坑日记：任何 bug/踩坑，当天记一条（日期 + 现象 + 根因 + 教训）。
4. 观点学习：看到有价值的观点/教训，随手记，标注来源和时间。

## 定期复盘闭环（核心）

| 频率 | 动作 | 落在哪 |
|---|---|---|
| 每日 | 自动跑 `close_review.py`，体检持仓/净值/次日关注 | `04_每日复盘/复盘_*.md` |
| 每周 | 人工填「周复盘清单」→ 查胜率偏差 → 改进策略 | `06_复盘/复盘模板与节奏.md` |
| 每月 | 人工填「月复盘清单」→ 对基准 → 重跑回测 | 同上 + 3 本回测本 |

**闭环铁律**：改任何 `config.py` 参数前，先跑回测验证 → 结论写回对应回测本 → 生效值同步进 config.py → 踩坑/观点随手沉淀。
