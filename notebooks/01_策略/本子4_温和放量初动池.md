# 本子 4 · 温和放量初动池（第3正式策略）

> 定位：短线（3天）+ 趋势（波段2-4周）之外的**第3路正式策略**——「低位蓄势后温和放量初动」，T+5。
> 权威参数见 `scripts/warm_start_entry.py` 模块级常量（**注意：不在 config.py**，本策略参数独立成模块）。
> 2026-09-20 由观察池升级为正式策略（回测翻正 + 用户拍板）。

## 一、核心逻辑

初动 = 低位横盘蓄势后**温和放量**（非爆量）启动的「第一波初动」。与右侧趋势的区别：
右侧追「放量突破」的右侧确认点；初动池抓「刚起量的第一口」——量比 1.3-2.5x（温和），5日涨幅 +3~8%（已启动但未透支）。

## 二、选股条件（最优档，回测固化）

| 维度 | 条件 | 常量 |
|---|---|---|
| 量比 | 1.3~2.5x（温和放量，非爆量） | `LB_LO`/`LB_HI` |
| 5日涨幅 | +3~+8%（启动但未透支） | `CHG5_LO`/`CHG5_HI` |
| 60日位置 | <80% | `POS60_MAX` |
| 均线结构 | 站上 MA20 + MACD 多头 | 内置 |
| 当日涨幅 | -9.5% ~ +9.5%（防涨停/跌停追高） | `CHG_TODAY_MAX/MIN` |
| 当日振幅 | ≤7.5% | `AMP_TODAY_MAX` |
| 成交额 | ≤16亿 | `AMT_MAX` |
| 周线共振 | 周收 > 25日周均 且 周均上行（盈亏比+38% 最大增益来源） | `week_up` |
| 保守蓄势 | 前10日平均振幅≤3.5% 且 前10均量/前60均量≤0.70 | `CONSOL_AMP10_MAX`/`CONSOL_VOL10_60_MAX` |

## 三、出场规则（V2 已固化，2026-09-20 用户拍板直接采纳）

| 规则 | 值 |
|---|---|
| 入场 | 信号日 T 收盘确认 → **T+1 开盘介入** |
| 硬止损 | **-8%**（止损价=现价×0.92） |
| 破MA5离场 | 持有 T+2 收盘起，收盘 < MA5 → **次日开盘离场** |
| 止盈 | 无固定止盈，让利润奔跑 |
| 最长持有 | T+5 收盘强制离场 |
| 大盘过滤 | **不设开闸**（回测证伪：弱市信号胜率 69.2% 反超强市 50.3%） |

## 四、回测结论

| 指标 | 基线（1366 信号） | V2 固化后 |
|---|---|---|
| T5 胜率 | 59.0% | 54.3%（代价 -4.7pp） |
| T5 均值 | +4.20% | — |
| 盈亏比 | 3.07 | **4.46** |
| 最大亏 | -12.3% | **-9.3%** |

- 660 天扩样本（2024-04~2026-09，腾讯源 1092 只），`warm_start_backtest.py`。
- 「周线共振」是最大增益来源（盈亏比+38%）；「回踩不破」弱化不启用。
- 注意：本策略**无独立台账 CSV**，推荐记录走 `data/笔记本/策略笔记本_温和放量初动池.md`。
