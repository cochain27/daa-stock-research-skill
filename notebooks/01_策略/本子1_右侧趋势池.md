# 本子 1 · 右侧趋势池（波段右侧追启动）

> 定位：波段右侧，追「横盘紧凑后的放量启动」，做 2-4 周波段。
> 权威参数见 `scripts/config.py` 的「右侧趋势通道参数」段。

## 一、核心逻辑

右侧趋势 = 不抄底、不等深跌反弹，而是**在横盘蓄势后放量突破的右侧确认点入场**。

## 二、选股条件（硬门槛，缺一不可）

| 维度 | 条件 | 参数 |
|---|---|---|
| 代码白名单 | 主板(60/00)+创业板(30) | `ALLOW_CODE_PREFIX` |
| 流通市值 | ≥30 亿（避流动性风险） | `TREND_MIN_MARKET_CAP` |
| 60日位置 | 30%~70%（下限挡深跌弱势，上限挡高位追涨） | `TREND_MIN_60D_POS_LOW` / `TREND_MIN_60D_POS` |
| 近20日振幅 | <25%（横盘不暴涨暴跌） | `TREND_MAX_20D_AMPLITUDE` |
| 近20日波动 | 收盘标准差/均价 <5%（横盘紧凑） | `TREND_MAX_20D_STD_RATIO` |
| 放量突破 | 成交量 ≥ 20日均量 ×1.5 | `TREND_BREAKOUT_VOL_RATIO` |
| 突破涨幅 | 3%~7%（不追一字板，也不追弱突破） | `TREND_BREAKOUT_CHG_RANGE` |
| 成交额 | >1.5 亿 | `TREND_MIN_AMOUNT` |

## 三、风控规则

| 规则 | 值 | 参数 |
|---|---|---|
| 止损 | -6% | `TREND_STOP_LOSS` |
| 止盈1 | +8% 减半 | `TREND_TAKE_PROFIT_1` |
| 止盈2 | +10% 清仓 | `TREND_TAKE_PROFIT_2` |
| 结构止损 | 收盘跌破 MA20 离场 | `TREND_STRUCTURE_STOP` |
| 目标持仓 | 14-28 天 | `TREND_HOLD_DAYS` |
| 每日上限 | 2 只 | `TREND_MAX_PICKS` |
| 温度闸门 | ≥55 才开仓 | `TREND_TEMP_MIN` |

## 四、展期机制（少数转中长期）

- 满 14 天触发展期评估：盈利>0、价>MA10>MA20、同时展期≤2 只。
- 展期硬上限 60 天强制离场。
- 展期后双档止盈：+10% 减半 / +15% 清仓（基于成本价）。
