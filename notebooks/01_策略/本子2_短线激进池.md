# 本子 2 · 短线激进池（情绪驱动）

> 定位：情绪驱动，追涨停梯队/冲板/接力强势股，3-5 天快进快出。
> 权威参数见 `scripts/config.py`「短线通道选股」+「短线策略参数」段。

## 一、核心逻辑

短线不看基本面看**情绪**：涨停家数代表赚钱效应，赚钱效应打开才进场接力强势股。

## 二、开闸门槛（情绪门槛，先看大盘情绪再谈选股）

| 条件 | 值 | 参数 |
|---|---|---|
| 涨停家数 | ≥50 家 | `SHORTLINE_ZT_MIN` |
| 炸板率 | <40% | `SHORTLINE_ZB_RATE_MAX` |
| 情绪评分 | ≥60 分 | `SHORTLINE_MIN_SCORE` |
| 市场温度 | ≥50 | `SHORTLINE_TEMP_MIN` |

## 三、选股条件

| 维度 | 条件 | 参数 |
|---|---|---|
| 代码白名单 | 主板+创业板 | `ALLOW_CODE_PREFIX` |
| 最低涨幅 | ≥5%（冲板/强势票） | `SHORTLINE_MIN_CHG` |
| 连板上限 | ≤2（3板以上高位不追） | `SHORTLINE_MAX_LIANBAN` |
| 上影过滤 | 当日最高回撤>3% 剔除（冲高回落） | `SHORTLINE_MAX_UPPER_SHADOW` |
| 每日上限 | 2 只 | `SHORTLINE_MAX_PICKS` |

## 四、风控规则

| 规则 | 值 | 参数 |
|---|---|---|
| 止损 | -5.5% | `SHORT_STOP_LOSS` |
| 止盈1 | +5% 减半 | `SHORT_TAKE_PROFIT_1` |
| 止盈2 | 盈利>3%后跌破 MA10 清仓（移动止损，让利润奔跑） | `SHORT_TP2_ENABLED` |
| 移动止损 | 盈利>2% 上移止损至成本线 | `SHORT_TP_MOVE_UP` |
| 时间止损 | 持有≥3天仍浮亏离场 | `SHORT_TIME_STOP_DAYS` |
| 极限持有 | 5 天 | `SHORT_HOLD_DAYS_MAX` |

## 五、历史演变（重要，改前必读）

- **2026-09-09 入场门槛调整**：回测证明「量比≥2 + 剔昨日涨停」硬门槛会把短线最赚钱的接力强势票全滤掉（289→79 笔后反 -1.45%）→ 量比门槛关闭、剔昨涨停关闭，只靠情绪评分+温度闸门过滤。
- **2026-09-09 止损校准**：-4% 在 1.9 天持有期内被扫 60% → 改为 -5.5%。
- **2026-09-09 时间止损新增**：持有≥3天仍浮亏离场（回测 g0e1 有效）。
- **2026-09-09 上影过滤**：最高回撤>3% 冲高回落剔除 → 胜率 45.0→47.2%、盈亏比 1.59→1.69。

## 六、虚拟成交规则

推荐即虚拟成交，实时价入账，每笔 1 万元等权记账（`VIRTUAL_TRADE_AMOUNT`）。
